# VIDORA

واجهة أولية متجاوبة لأداة فيديو.

## الحالة الحالية
- صفحة هبوط عربية RTL ومتجاوبة.
- تحقق مبدئي من صيغة رابط TikTok في المتصفح.
- لا يوجد محرك تنزيل فعلي أو تسجيل دخول أو قاعدة بيانات أو عداد استخدام آمن أو مدفوعات حتى الآن.

## تشغيل محلي
افتح `index.html` في المتصفح أو استخدم أي خادم ملفات ثابت.

## مراحل الإنتاج التالية
1. تحديد مصدر تنزيل رسمي أو مرخّص يدعم المحتوى الذي يملكه المستخدم أو لديه إذن بتنزيله.
2. بناء API خلفي يتحقق من الإذن ولا يتجاوز الخصوصية أو قيود المنصة.
3. ربط Supabase Auth وقاعدة بيانات لفرض 4 تنزيلات ناجحة يومياً لكل مستخدم على الخادم.
4. إضافة بوابة دفع مناسبة لمصر، ثم لوحة إدارة.

لا تضع مفاتيح API أو أسراراً في ملفات الواجهة. لا تعتمد على localStorage لفرض الحصص المدفوعة.
